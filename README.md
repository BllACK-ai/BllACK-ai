# Hey, I'm BllACK 👋

I'm Amanama Wisdom James — a Mechatronics Engineering graduate from the Federal University of Otuoke, currently doing freelance engineering work while I dig deeper into machine learning and mathematical modeling applied to industrial and energy systems.

What I'm mostly interested in: taking real physical systems — power lines, solar setups, sensor data — and building models (physics-based or ML) that can actually predict, detect, or explain what's going on inside them. A lot of my projects start as "can I simulate this accurately enough to generate my own dataset" before the ML part even comes in.

## 🔧 Featured projects

- **[Fault detection in transmission lines using ML](https://github.com/BllACK-ai/Fault-detection-in-Tramission-line-using-ML)** — a full pipeline: physics-based circuit simulation → randomized fault injection → feature engineering → Random Forest models for fault-type classification and fault location, with noise-robustness testing built in.
- **[Solar power modeling and simulation](https://github.com/BllACK-ai/Solar-power-modeling-and-simulation)** — a PV system simulation suite covering panel modeling, MPPT control, daily system energy balance, and converter/thermal/cycle-life modeling.
- **[Machine Vision shape detector](https://github.com/BllACK-ai/Machine-Vision-shape-detector)** — a shape detection and recognition system using classical machine vision techniques.
